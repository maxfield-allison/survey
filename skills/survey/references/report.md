# A reusable survey report

Start with the recommended course and its conditions. Preserve enough evidence for a reader
who did not attend the investigation to assess the decision.

Use the sections the task needs, usually:

- Question, phase, constraints, decision criteria and coverage.
- Credible options, including the current approach; a table comparing the same dimensions.
- Findings with nearby evidence, contrary evidence and claim status.
- Judgement, rejected alternatives, consequence of error and concrete next step.
- Remaining unknowns and the check that could change the choice.
- Dated source register and, for extended research, a search record.

Do not force this outline onto a short answer. Avoid numerical scoring unless weights and
measurement actually describe the user's decision. Keep availability, source review, local
testing, deployment and user acceptance as separate claims.

Example of a conditional judgement:

> Retain B while testing A's restore path. A's documented throughput meets the requirement,
> but no comparable recovery result is available. A wins only if the bounded restore test
> meets the existing recovery objective without adding unacceptable upkeep.

That example supplies no real measurement, approval, owner or deadline.
